# העלאה לגוגל סקריפט ממחשב מסונן – סקיל לקלוד

סקיל ל-[Claude Code](https://claude.com/claude-code) שמאפשר לעדכן קוד של Google Apps Script גם ממחשב מסונן (למשל נטפרי), שבו ההעלאה הרגילה (`clasp push`) או השמירה בעורך של גוגל נחסמות.

## איך זה עובד
- הקוד נשמר במחסן **פרטי** שלך ב-GitHub.
- "רובוט" של GitHub Actions, שרץ על השרתים של GitHub, מעלה אותו לגוגל.
- לפני כל העלאה הרובוט בודק שאף אחד לא שינה את הפרויקט ישירות בגוגל. אם שינו – הוא עוצר ולא דורס.
- אחרי כל העלאה הרובוט משאיר "פתק" עם התוצאה, וקלוד קורא אותו ומספר לך אם הצליח ולמה לא.
- עובד עם כמה חשבונות גוגל וכמה פרויקטים יחד.
- פרויקט שלא נחסם – קלוד מעלה ישירות, בלי מחסן ובלי רובוט.

## מה צריך
- Claude Code (באפליקציה או בטרמינל).
- חשבון GitHub (חינם).
- Windows, Mac או Linux. נבדק על Windows.

את שאר ההתקנות (Git, Node.js, clasp) קלוד עושה או מדריך צעד אחר צעד.

## התקנה
מעתיקים את התיקייה `netfree-apps-script` אל תיקיית הסקילים של קלוד:
- Windows: `%USERPROFILE%\.claude\skills\`
- Mac / Linux: `~/.claude/skills/`

או פשוט מבקשים מקלוד:
> תתקין לי את הסקיל netfree-apps-script מהכתובת של הדף הזה

## שימוש
מבקשים מקלוד בשפה רגילה, למשל:
> תוסיף לפרויקט שלי בגוגל סקריפט פונקציה ששולחת מייל, ותעלה לגוגל

בפעם הראשונה קלוד ידריך בהקמה: פתיחת מחסן פרטי, חיבור חשבון גוגל והוספת הפרויקט. אחר כך כל עדכון הוא בקשה אחת.

## בטיחות ופרטיות
- המחסן שלך חייב להיות **פרטי**.
- פרטי ההתחברות לגוגל לא עוברים דרך הצ'אט – אתה מעתיק אותם בעצמך לכספת (Secrets) של GitHub.
- קלוד עובד רק על חשבונות שלך או של מי שנתן לך אישור.
- כל הפרטים האישיים (חשבונות, פרויקטים) נשמרים אצלך בלבד, לא בסקיל.
